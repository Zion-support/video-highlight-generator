# ✂️ Video Highlight Generator

Automatically detect and clip the best moments from long-form video into shareable highlights for social, OTT and broadcast.

**Live:** https://ziontechgroup.com/video-highlight-generator/

## Features
- Scene, speech and excitement detection to find peak moments
- Auto-crop to 9:16 / 1:1 / 16:9 with captions
- Batch processing for sports, webinars, podcasts and streams
- One-click export to social platforms and CMS
